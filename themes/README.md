# Themes

HTML/Blade temalar bu klasörde tutulur. Yeni tema eklemek için:

1. `themes/{tema-adi}/` altında `layouts/`, `partials/`, `pages/` oluşturun
2. `config/themes.php` dosyasına temayı ekleyin
3. Gerekirse Vite entry dosyalarını `resources/css/themes/` ve `resources/js/themes/` altına ekleyin

Aktif tema: **adminlte4** (AdminLTE 4.0.0)
